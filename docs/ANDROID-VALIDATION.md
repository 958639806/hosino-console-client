## 构建与安装

1. 使用 Node.js 24，按锁文件执行 `npm ci`、`npm run check`；需要浏览器回归时执行 `npx playwright install chromium` 和 `npm run test:e2e`。
2. 执行 `npm run android:sync`，确认本地 dist 进入原生项目；不通过远程网页替代打包资源。
3. 安装 Android Studio、Android SDK 36、Build Tools 35.0.0 和 JDK 21，使用生成工程的 Gradle wrapper（8.14.3），执行 `npm run android:open`。当前 minSdk 为 24，compile/target SDK 为 36；设备需 Android System WebView/Chrome 105 及以上，过旧时显示本地更新提示。
4. 在 Android Studio 构建并运行至模拟器或已授权 USB 调试的设备。命令行可在 android 目录运行 `./gradlew assembleDebug`；默认调试产物位于 `android/app/build/outputs/apk/debug/app-debug.apk`。
5. 调试 APK 仅用于开发验证。内部发布另配置持久化 release 签名并构建签名 APK；密钥与口令不进入源码或日志。记录 APK 校验值、commit SHA、versionName/versionCode、签名类型和构建工具版本。

未配置 Android SDK/JDK、无法下载构建依赖或构建失败时，记录原始失败项；资源构建成功不能替代 APK 构建成功。
