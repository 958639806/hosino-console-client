# 认证与数据边界

## 连接和凭据

- 仅接受 HTTPS 服务器根地址；不接受内嵌凭据、查询参数、片段和路径前缀。证书错误由环境修复，不关闭 TLS 校验。
- 手机只持有设备 access/refresh token，不持有 OpenClaw 网关凭据，也不保存控制台密码。
- Android 凭据通过原生安全存储保存；浏览器开发仅使用内存凭据，不能把 localStorage/Preferences 中的明文令牌当作安全持久化。
- 连接元数据、草稿和请求恢复记录与安全凭据分开。连接 ID 隔离数据，修改服务器地址时新建连接，避免旧凭据发往不同服务。
- 请求携带 `Authorization: Bearer`，写请求携带 `X-HS: 1`。token 不进入 URL、文件名、截图、控制台日志或分析事件；网络请求体/头也不做无筛选日志输出。

设备刷新会同时轮换 access/refresh；客户端串行刷新并在保存新凭据前不宣称恢复完成。网络失败不直接删除凭据。设备撤销和真正失效与离线、403 及服务端错误分别显示。

联网退出应先请求服务端撤销并清理本地安全凭据；撤销失败时仍清理本地，但只能说明“本地已退出，远端撤销未确认”。删除本地凭据不能证明服务器设备已撤销。退出和连接切换还应停止旧监听、阻止迟到结果写回当前页面、撤销临时 Blob URL；用户已经另行保存或分享的系统文件不属于应用能收回的范围。

## 执行请求与未知结果

requestId 在发送前持久化，绑定操作、目标和内容。普通轮询、网络恢复和前台恢复只读取状态，不执行待发送队列。超时、断网、5xx 和进程重建后优先查询既有回执；不会为了“重试”自动换 ID。CLI 断流与取消任务使用不同操作。

服务端在下游派发前持久化回执，重启遗留请求进入 unknown，防止再次派发。completed 指提交响应已经保存，不能据此宣称模型或进程已完成。结果无法确认时必须保留未知提示并允许核对历史；本实现不承诺跨外部系统的恰好一次副作用。

恢复记录只保存连接、会话、requestId、内容指纹和状态等元数据，不保存消息正文或令牌；草稿可能包含消息内容。这些仍属于用户数据，不应作为无敏感性的诊断日志输出。客户端首版不提供离线自动执行队列。

当前刷新接口立即轮换凭据；如果服务端已轮换而客户端未收到或未保存响应，旧凭据不能再次刷新，需要重新登录。安全存储读写失败会显示错误，不降级为明文持久化。

## 媒体与高权限操作

受保护媒体先通过鉴权请求获取 Blob，再生成临时预览 URL；长期令牌不拼接到图片、音频或下载链接。只向当前连接的受支持接口发送授权，不接受任意外部媒体地址作为携带 Bearer 的请求目标。Android 下载/分享将文件写入应用 Cache 再交给系统分享面板，退出或切换连接时清理该缓存；真实文件权限和分享行为待真机验证。

CLI 默认由后端拒绝，只有 `permissions.cli` 明确允许时开放；modules.cli 只表示接口能力存在。管理写操作仍需服务端校验，不能因为安装了客户端就新增配置写入或技能安装权限。控制台聊天与 QQ 实际投递必须显示不同目标，危险操作显示目标、影响和确认结果。

服务端持久化文件采用单进程存储并限制文件权限；设备凭据保存哈希，回执可能含业务结果，应纳入测试服务备份和访问控制。生产部署、网关重启和真实外部投递需要另行安排，不由客户端开发验证隐式触发。
